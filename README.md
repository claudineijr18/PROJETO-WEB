## 🎯 Sobre o Projeto

O **VidaKids** é um site educativo e interativo com foco em **informar, orientar e acolher famílias e cuidadores**, oferecendo conteúdo confiável sobre:

* Vacinação infantil 💉
* Primeiros socorros 🚑
* Dicas de rotina e bem-estar infantil 🌈

O projeto está alinhado à **ODS 3 - Saúde e Bem-Estar**, com foco na meta **3.2**, que visa reduzir a mortalidade infantil.

O trabalho foi desenvolvido em **duas etapas**, conforme solicitado pela disciplina **Programação Web Front-End**:

* **Projeto 1:** HTML + CSS
* **Projeto 2:** Funcionalidades com JavaScript (login, cadastro e painel administrativo)

## 🌈 Principais Funcionalidades

### 🔹 **Projeto 1 – Front-End (HTML + CSS)**

* Layout responsivo e infantil
* Uso de cores suaves e ícones amigáveis
* Seções informativas sobre cuidados infantis
* Rodapé com link de currículo (requisito obrigatório)

### 🔹 **Projeto 2 – Funcionalidades com JavaScript**

* Sistema de **login**
* Sistema de **cadastro de usuários**
* Armazenamento via **localStorage**
* Registros exibidos em tempo real
* Página **admin** contendo:

  * ✔ Lista de usuários cadastrados
  * ✔ Busca por nome ou e-mail
  * ✔ Exclusão individual 
  * ✔ Botão de limpar busca
* Código organizado, bem comentado e humanizado

## 🚀 Como Executar o Projeto Localmente

1. **Clone o repositório:**

```bash
git clone https://github.com/claudineijr18/PROJETO-WEB.git
```

2. **Abra o projeto no VS Code:**

```bash
code PROJETO-WEB
```

3. **Inicie pelo arquivo:**

```
login.html
```

4. O sistema funciona totalmente com **localStorage**, sem necessidade de servidor.
